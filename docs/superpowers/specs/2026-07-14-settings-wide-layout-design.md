# 设置页宽屏专业化布局设计

日期：2026-07-14

## 背景

当前设置页外层容器最大宽度为 `1160px`，桌面布局使用 `196px` 左侧导航、`24px` 列间距和 `28px` 水平内边距。在 1920px～2048px 宽屏上，页面两侧出现大量无效留白，主内容区却仍然偏窄：Agent 摘要卡文字容易换行，知识库文档表格的标题、标签和索引时间互相挤压。

本次采用已确认的 A（Balanced）方向：稳健扩宽到 1440px，通过内容宽度分级和更一致的信息层级提升专业感，不将设置页改造成无边界的全宽工作台。

## 目标

- 提高 1440px～2048px 桌面屏幕的有效空间利用率。
- 让 Agent 配置、知识库表格等高密度内容获得足够宽度。
- 保持阅读型表单的合理行长，避免所有内容机械拉满。
- 强化导航、卡片、工具栏和表格的视觉层级与对齐。
- 保持当前主题体系、路由、数据流和移动端行为。

## 非目标

- 不修改 API、路由、数据库或知识库业务逻辑。
- 不改变聊天页面的 `chat-container` 阅读宽度。
- 不引入新的品牌色、装饰性渐变、大型插画或第三方 UI 框架。
- 不将桌面设置页改为持续随视口扩张的全宽布局。
- 不重构设置页的功能分组或导航信息架构。

## 外层布局

### 桌面宽度

设置页主容器从 `max-width: 1160px` 调整为 `max-width: 1440px`，继续水平居中。

桌面网格使用：

```text
navigation width = 184px
column gap = 32px
content width = remaining space
```

页面水平内边距按视口分级：

- 宽屏：32px
- 普通桌面：24px
- 移动端：16px

在 1440px 视口下，容器受视口与 padding 限制，不产生横向滚动；在 1920px 和 2048px 下，内容最大宽度稳定为 1440px，保留克制的两侧留白。

### 导航

- 桌面端左侧导航保持在内容网格内，并在设置内容滚动时 sticky。
- sticky 顶部偏移与主内容顶部 padding 对齐，不遮挡 `PageHeader`。
- 选中项继续使用主题变量，但强化为柔和背景、清晰文字和轻量边界/强调标识，避免只呈现不明显的白色块。
- 小于 `1024px` 时沿用顶部横向滚动导航，不增加抽屉或汉堡菜单。
- 移动端导航项保持可触摸尺寸，关键导航不隐藏。

## 内容宽度分级

外层容器扩宽后，内容按用途分为两类：

### 工作区型内容

以下内容使用完整主内容宽度：

- Agent 身份与摘要区域
- 能力、技能、知识范围摘要卡
- 知识库列表与详情
- 文档表格、数据源列表和召回结果
- 模型或能力的多列管理视图

### 阅读型内容

Persona、组织默认人格、YAML 编辑、单列表单和长说明内容使用约 `960px` 的阅读上限。限制作用在具体面板内部，而不是缩回整个设置页容器，因此侧边导航与各页面起始线仍保持一致。

## 视觉层级

继续使用现有 CSS 主题变量和 `professional-card` 语言，通过一致性而不是装饰提升质量：

- 页面或对象标题：20～22px，使用紧凑字距。
- 卡片标题：14～15px。
- 辅助说明：12～13px，并维持可读行高。
- 卡片统一圆角、边框、内边距和常态轻阴影。
- 普通卡片不使用悬浮层级感；只有明确可点击卡片保留 hover 反馈。
- 区块间垂直间距统一，避免相邻卡片之间忽大忽小。
- 操作按钮与对应标题或工具栏对齐，不漂浮在不相关的行高上。

## Agent 页面

Agent 页保留当前信息顺序：

1. Agent 身份、模型和新建/删除操作。
2. Persona 摘要。
3. 能力、技能和知识范围摘要。

底部三张摘要卡在桌面端保持三列等高；卡片标题、计数和编辑操作对齐。摘要正文采用稳定的截断/换行规则，不能因为工具名称较长而破坏卡片高度。中等屏幕允许自然变为两列或单列。

## 知识库页面

### 详情头部和 Tab

- 嵌入设置页时继续使用紧凑 breadcrumb，不重复设置页主标题。
- breadcrumb、Tab、搜索工具栏使用相同的内容起始线。
- Tab 高度、选中态和间距保持紧凑；数量作为次要信息，不扩大 Tab 宽度。
- 搜索框、结果数量和主操作按钮在同一水平基线上；窄屏下允许换行，但操作顺序保持不变。

### 文档表格

文档表格使用扩宽后的完整内容区，并明确列职责：

- 标题列：弹性占据剩余空间，标题优先展示；URL 单行截断。
- 来源、状态、切片数：紧凑固定或最小宽度。
- 标签列：获得稳定的最小宽度，标签过长时使用受控换行或截断。
- 索引时间：保持足以显示两行时间的宽度，不被压成逐字换行。
- 操作列：固定在右侧并保持按钮间距一致。

当视口不足以容纳合理列宽时，表格容器横向滚动，不能持续压缩成不可读的多层文本。表头与数据列必须严格对齐。

## 响应式规则

- `>= 1280px`：1440px 最大容器、184px 导航、32px 列间距，工作区面板充分扩展。
- `1024px～1279px`：容器贴合视口、24px 水平 padding；仍可保留两列布局，列间距适当收紧。
- `< 1024px`：设置页切换为单列，导航变为顶部横向滚动条。
- `< 768px`：16px 水平 padding；工具栏和多列摘要卡堆叠；表格使用横向滚动。

断点以实际内容不溢出为准，但不得引入与现有 Tailwind 断点体系冲突的自定义全局断点。

## 组件与样式边界

预计修改范围：

- `frontend/src/components/SettingsView.tsx`
  - 设置页外层网格、导航 sticky、内容宽度分级入口。
- `frontend/src/components/KnowledgeView.tsx`
  - 嵌入态详情头、Tab/工具栏和文档表格列布局。
- `frontend/src/index.css`
  - 新增少量可复用的设置页容器或面板宽度类；避免散落重复尺寸。
- 对应的前端组件测试。

优先复用现有 `CARD`、`professional-card`、主题变量和 Tailwind 工具类，不为了本次宽度调整拆分无关组件。

## 状态与边界情况

- loading、空列表和错误提示应与正常内容使用相同起始线和宽度。
- 长 Agent 名称、长模型名称、长工具名称和中英文混排不能撑破卡片。
- 知识库标题、URL、标签和状态文本必须有明确的换行或截断策略。
- sticky 导航不能创建第二个独立滚动容器，也不能遮挡主标题。
- 弹窗和抽屉保持现有最大宽度，不随设置页主容器一起扩张。
- 页面路由、刷新恢复和当前 Tab 状态不受布局变化影响。

## 测试与验收

### 自动化测试

- 更新 `SettingsView` 测试，验证外层宽屏容器、桌面导航和响应式结构的关键类名或语义结构。
- 更新 `KnowledgeView` 测试，验证嵌入态工具栏和文档表格保留可滚动容器及稳定列结构。
- 运行完整 Vitest 测试、TypeScript 构建和 Vite production build。

### 视觉验证

在浅色主题下至少检查以下视口：

- 2048×1152
- 1920×1080
- 1440×900
- 1024×768
- 768×1024

重点确认：

1. 1920px 以上页面不再出现截图中的大面积无效留白。
2. 主内容不贴边，整体仍有明确中心区域。
3. Agent 三张摘要卡等高，无异常溢出。
4. 知识库表格标题、标签、时间和操作列不发生不合理挤压。
5. 横向导航和移动端工具栏仍可完整操作。
6. 中英文切换不会造成明显布局跳动。

## 验收标准

1. 桌面设置页最大内容宽度为 1440px，导航宽度约 184px。
2. 信息密集面板使用完整主内容宽度，阅读型面板保持约 960px 上限。
3. 桌面导航 sticky，1024px 以下切换为横向导航。
4. Agent 页面摘要卡层级一致、等高且可处理长内容。
5. 知识库文档表格在宽屏上显著减少换行，在窄屏上通过横向滚动保持可读。
6. 不改变业务逻辑、路由、数据接口和聊天页面宽度。
7. 前端测试、类型检查和生产构建通过，目标视口视觉检查无阻断问题。
